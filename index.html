How to get your ad codes

Hi Insiders!

We made this guide for anyone having trouble getting their ad codes.

You don't need to submit codes for the videos you've already posted. If we need one, we'll ask you directly. Those videos are still counted as usual, so please don't worry.

From now on, just add the codes for each new video you post.

TikTok Spark Ads code

  1. Open the video on your profile and tap the three dots.

    The video must be public.

  2. Tap Ad settings.

    It is in the bottom row of icons. Swipe the row left if you don't see it.

    Ad settings

  3. Turn on Ad authorization.

    Accept the terms if TikTok asks.

    Ad authorization

  4. Tap Generate code and select 60 days.

    Please choose 60 days, not 7 or 30.

    Generate code
    7 days30 days60 days365 days

  5. Tap Copy code.

    Copy code

Instagram Partnership ad code

  1. Open the Reel on your profile and tap the three dots.

    You need a creator or business account.

  2. Tap Partnership label & ads.

    Partnership label & ads

  3. Turn on Get partnership ad code.

    Get partnership ad code

  4. Tap Copy.

YouTube Shorts No ad code needed

YouTube Shorts has no ad code. Just write N/A in the code field.

Add these four things for each new video

  • TikTok video link
  • TikTok Spark Ads code, set to 60 days
  • Instagram Reel link
  • Instagram partnership ad code

If you have any trouble getting an ad code, just write N/A in its place.

If something doesn't work

  • You can't find Ad settings on TikTok. Update the app. If it is still missing, go to Settings and privacy, then Creator tools, and turn on Ad settings there.
  • TikTok won't generate a code. This often happens when the video uses a sound that is not cleared for commercial use. Use your own original sound or a track from the Commercial Music Library.
  • You can't find the Instagram option. Switch to a creator or business account in Settings, then try again.
  • The code expires. Just generate a new one the same way.

Button pictures are illustrations. Names and positions can differ slightly depending on your app version.
